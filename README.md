## Getting Started

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

### Build the project for production

```bash
npm run build
```

### Preview the production build

```bash
npm run preview
```

---

## Testing

### Run all tests

```bash
npm run test
```

### Run tests with coverage report

```bash
npm run test:coverage
```

### Open the interactive test UI

```bash
npm run test:ui
```

---

## Code Quality

### Lint code

```bash
npm run lint
```

### Check formatting

```bash
npm run format
```

### Fix formatting

```bash
npm run format:fix
```

---

> ✅ Git pre-commit hook runs `lint`, `format`, and `test:coverage` automatically via Husky.
